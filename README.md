# 🔭 Argus — Projeto Antigo

> **Observe. Analise. Organize.**

> ⚠️ **Este repositório contém uma versão antiga do projeto Argus e não representa a versão atual em desenvolvimento.**
>
> O desenvolvimento atual do Argus está sendo realizado em uma nova estrutura, utilizando **React + TypeScript**. Este repositório é mantido como **registro da versão anterior do projeto**, servindo como referência para a evolução da interface, ideias, funcionalidades e identidade visual.

O **Argus** é uma plataforma de monitoramento e análise de utilização de computadores desenvolvida no contexto do curso técnico de **Informática para Internet do SENAI**.

A proposta do projeto é fornecer às organizações uma visão centralizada sobre a utilização de seus computadores, permitindo transformar dados de uso em informações que possam auxiliar na análise, organização e tomada de decisões.

O Argus busca unir **monitoramento, análise de dados, desenvolvimento web e uma interface moderna**, criando uma experiência simples para administradores e gestores.

# 📌 Sobre o Projeto

O Argus surgiu a partir da necessidade de criar uma solução capaz de auxiliar empresas no acompanhamento da utilização de seus recursos computacionais.

A ideia não é apenas coletar dados, mas **transformar informações de utilização em uma visão organizada da operação**.

> ⚠️ **Status desta versão:** este repositório corresponde à implementação anterior do projeto. A estrutura e a interface aqui presentes foram utilizadas como base para a reconstrução e evolução do Argus.

Entre os principais recursos planejados estão:

* 📊 Monitoramento de computadores;
* 🌐 Acompanhamento de sites utilizados;
* 💻 Monitoramento de aplicações;
* ⏱️ Análise do tempo de utilização;
* 📈 Indicadores e métricas;
* 📋 Relatórios;
* 👥 Gerenciamento de usuários;
* 🔐 Autenticação e controle de acesso;
* ⚙️ Configurações;
* 🖥️ Dashboard administrativo;
* ⬇️ Sistema de download;
* 🔄 Histórico de atualizações;
* 💳 Sistema de planos e monetização.

# 🎯 Objetivo

O principal objetivo do Argus é desenvolver uma solução capaz de auxiliar empresas no **gerenciamento e análise da utilização de computadores**, oferecendo uma visão mais clara sobre os recursos utilizados no ambiente corporativo.

O projeto busca transformar dados técnicos em informações mais fáceis de compreender.

A proposta combina:

* Desenvolvimento Web;
* Monitoramento;
* Análise de dados;
* Interface intuitiva;
* Experiência do usuário;
* Segurança;
* Organização de informações;
* Administração de sistemas.

Além do objetivo tecnológico, o Argus também representa uma aplicação prática dos conhecimentos adquiridos durante o curso técnico.

# 💡 A Ideia por trás do Argus

O nome **Argus** faz referência a **Argos Panoptes**, figura da mitologia grega conhecida por possuir muitos olhos.

A escolha representa a ideia central do sistema:

> **Observar o ambiente, reunir informações e transformar aquilo que é observado em conhecimento útil.**

Essa ideia também influencia a identidade visual e a experiência da plataforma.

O conceito do Argus está relacionado a:

👁️ Observação
🔭 Monitoramento
📊 Análise
💻 Tecnologia
🔐 Segurança
⚙️ Controle
📈 Organização
